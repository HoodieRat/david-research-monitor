# Contributing

Open an issue describing the change before large feature work. Keep changes focused, document user-facing behavior, and run `dotnet build DavidResearchMonitor.sln`, `dotnet test DavidResearchMonitor.sln`, and `python scripts/check_secrets.py` before proposing a pull request.

Use fictional, non-identifying data in tests, screenshots, and examples. Never commit credentials, browser profiles, SQLite research data, reports generated from private sources, or logs. When changing AI providers, preserve the LM Studio local option and the user's explicit provider selection.
