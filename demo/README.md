# David Research Monitor demo

The MP4 is a narrated, 3 minute walkthrough of the Windows app. It covers setup, AI provider choice, topics, scheduling, the LinkedIn read switch, chosen-content capture, running research, and reading and saving results.

Privacy: the app was launched with an isolated sample SQLite database. Every topic, source, post, and report shown is fictional. No personal LinkedIn account or browser profile was opened or recorded. The recording captures only the Research Monitor window, and sample file paths are masked in the finished video.

Files:

- `David-Research-Monitor-Demo.mp4` — shareable video with synthetic narration
- `David-Research-Monitor-Demo.srt` — optional captions
- `David-Research-Monitor-Demo-Transcript.md` — narration transcript

This is a sample walkthrough. Its LinkedIn pages and report findings are illustrative, not a recording of a live LinkedIn session.
